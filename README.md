# 🏁 Mon petit District

*Le foot amateur en direct.*

Suivi en direct des matchs de foot amateur (D3, D4…), là où il n'y a ni live ni live-scorer.

## Fonctions (version démo)
- Liste des matchs : en direct, à venir, résultats
- Score en live : coup d'envoi, mi-temps, fin, chrono automatique
- Buts (buteur + minute), cartons jaunes et rouges, bouton « Annuler »
- **Classement en direct** : il intègre les matchs en cours, avec des flèches ▲▼ qui montrent les changements de place
- Réglages : nom de la poule, équipes, couleurs et **logo de chaque club** (import depuis le téléphone)

> Les logos des clubs appartiennent aux clubs : ils ne sont pas inclus dans le dépôt, chacun les importe dans l'app (avec l'accord du club pour un usage public).

Première compétition : **D3 District Haute-Marne – Poule A (2026/2027)**, classement de départ après la 8e journée.

Barème : victoire 3 pts, nul 1 pt, défaite 0 pt, forfait −1 pt. Départage : différence de buts, puis buts marqués.

## Limite actuelle
Démo locale : les données sont enregistrées dans le navigateur (localStorage), donc seulement sur l'appareil utilisé.
Prochaine étape : base temps réel (Firebase) pour que tous les spectateurs voient le score en direct.
